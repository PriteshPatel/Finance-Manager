## Feature Flowchart

```
User Opens Settings Tab
        ↓
   View Current Currency
        ↓
   Select New Currency
        ↓
  ┌─────────────────────┐
  │ setSelectedCurrency │
  └─────────────────────┘
        ↓
  ┌─────────────────────────────────┐
  │ CurrencyContext State Updates   │
  └─────────────────────────────────┘
        ↓
  ┌──────────────────────────┐
  │ Save to localStorage     │
  │ Key: selectedCurrency    │
  └──────────────────────────┘
        ↓
  ┌─────────────────────────────────┐
  │ All Components Re-render        │
  │ (using useFormatCurrency hook)  │
  └─────────────────────────────────┘
        ↓
  ┌────────────────────────────────────┐
  │ All Amounts Display New Currency   │
  └────────────────────────────────────┘
        ↓
  ┌────────────────────────────────────┐
  │ User Refreshes Browser             │
  │ Currency Persists from localStorage│
  └────────────────────────────────────┘
```

    │     └─ Access selectedCurrency state           │
    └────────────────────────────────────────────────┘
         │
    ┌────▼──────────────────────────────┐
    │  Settings Component               │

    └──────────────────────────────────┘

## Integration Points

### In Dashboard
```tsx
// Import
import { useFormatCurrency } from '../hooks/useFormatCurrency';
import { useCurrency } from '../context/CurrencyContext';

// Use
const formatCurrency = useFormatCurrency();
const { selectedCurrency } = useCurrency();

// Display
<div>{formatCurrency(amount)}</div>
```

### In Any Component
```tsx
// Example: Income Manager
const formatCurrency = useFormatCurrency();
return (
  <Card>
    <p>Total Income: {formatCurrency(totalIncome)}</p>
  </Card>
);
```
